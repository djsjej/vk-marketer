### Ключевое решение: Pivot на TargetHunter

**Проблема:** наш собственный парсер `/vk_audience` упёрся в VK API
flood control (error 9) при попытке полного парсинга 12 групп.
Service token блокируется на 15-60 минут после агрессивного использования.

**Решение:** Vizit предложил, Боба согласился — использовать TargetHunter
(стандартный профессиональный инструмент VK маркетологов с 2015 года) для
парсинга, наш бот только принимает готовый файл и грузит в VK Ads.

**Результат:** реализована команда `/upload_audience` (Phase 5.8) которая
принимает txt с VK ID и создаёт remarketing-сегмент через
`VKAdsClient.create_remarketing_users_list()`. 14 новых тестов, всё зелёное.

Наш собственный парсер `/vk_audience` оставлен для ad-hoc проверок,
основной канал — TargetHunter.

### Phase 5.7: Фильтр аудитории по активности

Vizit поднял вопрос про чистоту базы (мёртвые/неактивные аккаунты). Проверка
показала: `AudienceFilter` имел логику для `deactivated`, но не был подключён
к workflow `/vk_audience`. Технический долг с ночной сессии 14-15.05.

Сверка с Бобой: 14 дней неактивности — компромисс между чистотой базы и
сохранением живых аккаунтов (православная женщина 45-58 заходит раз в 3-5
дней). Реализован новый параметр `min_last_seen_days` в AudienceFilter +
подключён к /vk_audience.

### Реальный сбор базы через TargetHunter

Vizit прошёл полный цикл:

1. **Поиск сообществ** в TargetHunter по ключам: православие, батюшка,
   монастырь, храм, икона, святой, молитва, поминовение, помянуть, упокой
2. **Результат:** 1437 правосл. сообществ найдено
3. **Ручная отсортировка:** 484 хороших оставлено, остальные выкинуты
4. **Парсинг подписчиков** с фильтром «состоят в 3+ из этих групп»: 860 947 ID
5. **Финальные фильтры** через universal user_filter в TargetHunter:
   активные за 14 дней + минус подписчики pomolimsy + только живые +
   только с фотографией
6. **Финал: 619 146 чистых горячих ID**
7. **Загрузка через `/upload_audience`** в наш бот → создание сегмента

коммерческое). Креативы должны быть нейтральными и тёплыми, без
упоминания пожертвований/коммерции/монастыря.

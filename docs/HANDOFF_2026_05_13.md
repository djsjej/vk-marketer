## 🎯 Где остановились

### Phase 3.5 ✅ ЗАКРЫТА — создание кампаний работает

**Кампания `20976418` создана через бота 13.05.2026:**
- 6 групп по возрастам 41-58
- 6 объявлений с иконой Богородицы
- Заголовок «Молитва хранит наших воинов»
- В кабинете VK всё рендерится правильно

**Ключевое открытие сессии:**
VK работает в режиме **CBO** (Campaign Budget Optimization). На уровне кампании задаётся **общий** дневной бюджет, и **тот же бюджет передаётся на каждой группе** (одинаковое значение). VK сам распределяет между группами.

Поле `budget_optimization_enabled` — **read-only** в API, нельзя передавать через POST.

Минимум `budget_limit_day` для package 3122 = **100₽/день** (из UI кабинета). Рекомендуется 420₽/день для лучших результатов.

### Что НЕ доделано (мини-баг)

В Telegram-боте после создания кампании показывает «Объявлений: 0», хотя в кабинете VK создано 6. **Парсинг ответа неправильный** — VK возвращает banner_ids в другом месте чем мы ожидаем. Поправить в `src/services/ad_creator.py::_parse_create_response`.

## 🤖 Биба упал — нужно починить

**В конце сессии Vizit вызвал `/biba` в боте — Биба упал.**

Текст ошибки **Vizit не успел прислать**. У него на экране была:
```
❌ Биба упал в обморок:
`<какая-то ошибка>`
```

**Возможные причины которые надо проверить первым делом:**

1. **`/urls/` endpoint без `.json`** — отличается от других, в `_request` может падать на парсинге JSON
2. **`/transactions.json`, `/ad_plans.json`** — могут требовать обязательные параметры
3. **Filesystem на Railway** — `docs/biba_findings/` может не иметь прав на запись (по умолчанию у Railway контейнер пишет норм, но проверить)
4. **`_request` приватный метод клиента** — может не иметь экспорта/нужного интерфейса. Я в Бибе делаю `await client._request("GET", path)` — это нестандартный pattern
5. **Импорт** `from src.biba.proposals import ...` внутри функции — может циклически зависеть

**Первое действие в новом чате:**
Попроси Vizit'а прислать **текстом** (он сейчас в новом чате) сообщение об ошибке от `/biba`. Без этого — гадание.

## Кто такой Vizit и что строим

**Vizit** — основатель православного VK-сообщества **pomolimsy**
(vk.com/pomolimsy, 62 623 подписчика). Бизнес-модель: люди пишут имена
близких для поминовения за добровольное пожертвование.

**Цель:** построить **Рекламную Организацию Vizit** — самообучающуюся
систему ИИ-агентов которая привлекает в pomolimsy новых подписчиков
из правосл. аудитории VK через таргетированную рекламу.

**Целевая аудитория:** женщины 41-58, Россия, православные верующие,
замужние, с детьми.

## Кто с кем общается

**Vizit ↔ Claude** через **Claude.ai мобильный** — основной канал
разработки и стратегии. Vizit на iPhone, ему удобны короткие ответы
прозой без буллетов.

**Vizit ↔ Telegram-бот** через `@Zkakcjwkkxnrbot` — рабочий канал на
проде. Кнопки запускают инструменты (парсинг аудитории, статус кампаний,
ремаркетинг).

Боба, Рита, Кирилл, Тимур, Алина — **подчинённые Claude** (через Бобу),
не Vizit'а. Vizit с ними напрямую не общается, всё через Claude.

## Главные правила работы Claude (из INSTRUCTIONS.md v1.3)

1. **Сверка с Бобой обязательна** перед стратегическими решениями.
   Я применяю `BOBA_PERSONA` из `src/agents/personas.py` как mindset —
   жёсткий VK-гуру с 13-летним стажем, фокус на стратегии, не любит
   изобретать велосипед, уважает только результат.

2. **Держусь сценария разработки** — не реагирую на каждую идею Vizit'а
   мгновенно. Сначала сверяюсь с планом и Бобой.

3. **Не догадываюсь про VK API** — если структуры endpoint нет в
   документации (`docs/VK_API_*.md`) или в карте Бибы — прошу Vizit'а
   прислать страницу `https://ads.vk.com/doc/api/...`.

4. **Тестирую локально** через pytest+respx до push'а в прод. Vizit
   не должен быть тестировщиком.

5. **Mobile-friendly ответы** — Vizit на iPhone, экран маленький.
   1-2 абзаца прозой для простых вопросов, не больше 2 экранов для
   сложных. Без буллетов и списков в обычном общении.

## Текущий статус (15.05.2026)

**Что работает в проде:**
- Telegram-бот с фото-flow (фото + подпись → 4 варианта от Claude → создание кампании)
- VK Ads клиент (OAuth+PKCE, создание кампаний, ремаркетинг через `/api/v3/...`)
- Парсер VK сообществ через VK API service token (Standalone-приложение)
- Команда `/vk_audience` — собирает горячую аудиторию (пересечения подписчиков 4 правосл. сообществ) и автозагружает в VK Ads как remarketing-список
- Команда `/boba` — диалог с Бобой через Anthropic API (без tool use)
- Команда `/agent` — старый разговорный режим с Таргетологом
- Команда `/biba` — карта функционала VK Ads API

**Что НЕ работает / не сделано:**
- Tool use у Бобы (Phase 7) — сейчас Боба только разговаривает, действий не делает
- Подчинённые Бобы (Рита, Кирилл, Тимур, Алина) — только персоны в коде
- База знаний (Phase 9) — не реализована
- Поиск групп через `groups.search` — service-token даёт ошибку 1051
  (требует user-token через PKCE flow, Phase 12)

**Накопленные данные о ЦА:**
- 4 проверенных открытых правосл. сообщества: pravoslavnie_hristiane (109k),
  p_trapeza (224k), orthodoxpsiholog (406k), ortodoxia (69k)
- 4 сообщества скрыли подписчиков (error 15): veruyu, orthodox_woman,
  pravoclavie, pravoslavie_fm — убраны из seed
- В тест-режиме (5000/группа): 17 656 уникальных, 1 942 горячих в 2+ группах
- На полном парсинге ожидается ~50-100k горячих
- VK Ads требует минимум 2000 ID для создания ремаркетинг-списка

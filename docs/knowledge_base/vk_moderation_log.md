# Лог модерации VK Ads

Что отклоняла модерация и за какие нарушения. Каждая запись — урок
для Кирилла (креативщика) на будущее.

## Формат записи

```markdown
## Отклонено: <короткое название креатива>

**Дата:** YYYY-MM-DD
**Кампания:** ID или название
**Креатив:** Что было — текст + описание изображения
**Причина отказа (от VK):** Точная формулировка из кабинета
**Пункт правил VK:** Например «3.1 Текст на изображении»
**Что исправлено:** Что переделали, прошла ли модерация после
**Урок на будущее:** Что Кирилл (и я) должен помнить
```

## Правила VK Ads (зафиксированные на 15.05.2026)

Полная страница: https://target.vk.ru/help/advertisers/moderation/ru

### Изображения
- Текст на изображении ≤ 20% площади
- Без эмодзи и спецсимволов
- Без агрессивной цветокоррекции
- Изображения людей — только с письменного согласия
- Без склейки нескольких картинок
- Без сравнений «до/после»
- Без имитации интерфейса (кнопки call-to-action в самой картинке)
- Без сцен похорон и шокирующего контента
- Без обнажённого тела, без провокационных поз

### Тексты
- Слова заглавными — только аббревиатуры/бренды
- Без обещаний чудес/исцеления (для православной ниши)
- Без оскорблений, ненормативной лексики
- Без упоминаний трагических событий (убийство, смерть, теракт)
- Без агрессивных кликбейтов

### Запрещённые тематики
- Алкоголь, табак, оружие
- Наркотики, азартные игры
- Эзотерика (важно! Православная тематика — это **не** эзотерика,
  но границы размыты, может приходить отказ)

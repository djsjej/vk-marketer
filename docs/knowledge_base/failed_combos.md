# Провальные связки

Сегменты + креативы которые **не сработали** или были отклонены модерацией.
Учимся на ошибках чтобы не повторять.

## Формат записи

```markdown
## Провал: <короткое название>

**Период:** YYYY-MM-DD — YYYY-MM-DD
**Бюджет потрачен:** XXX₽
**Сегмент:** Описание
**Креатив:** Описание

**Метрики (плохие):**
- Показы: XXX
- Клики: XX
- CTR: 0.X% (ниже нормы 0.5%)
- CPL: XXX₽ (выше нормы 50₽) ИЛИ конверсий вообще не было

**Причина (гипотеза):** Почему не сработало?
- Неверный сегмент (слишком широко / слишком узко)
- Неверный креатив (не цепляет, не релевантен)
- Неверный посыл (давление / манипуляция / фальшивая срочность)
- Модерация отклонила (см. подробности в vk_moderation_log.md)
- Технические проблемы (ошибки в кампании)

**Что бы попробовать по-другому:**
- Сузить/расширить сегмент по такому-то признаку
- Переписать креатив с акцентом на X
- Заменить образ

**Источник:** VK Ads статистика, запись от Алины + анализ Бобы
```

# База знаний Рекламной Организации Vizit

**Назначение:** Накопление опыта между циклами. Без этой папки каждая
кампания — одноразовый эксперимент. С ней — реальное обучение
организации, CPL снижается от цикла к циклу.

**Кто пишет:** Алина (через инструмент `append_knowledge` после Phase 8),
Боба (через `append_knowledge` для общих наблюдений), Vizit (руками
если нужно зафиксировать что-то срочное).

**Кто читает:** Боба (через инструмент `read_knowledge` перед каждым
циклом для проверки что уже известно), Claude и Vizit когда нужно
посмотреть руками.

## Файлы

- `working_combos.md` — рабочие связки сегмент+креатив с CPL и периодом
- `failed_combos.md` — провальные связки с причинами почему не сработало
- `hypotheses.md` — текущие гипотезы на тестировании, ожидают результата
- `vk_moderation_log.md` — что забанили или отклонила модерация и за что
- `orthodox_calendar.md` — православный календарь для сезонности кампаний

## Принципы записи

**1. Гипотеза → Тест → Замер → Вывод → Масштаб.**
Любое утверждение — это либо подтверждённый факт (с цифрами/датами),
либо гипотеза (помечено как «гипотеза»). Не путаем одно с другим.

**2. Минимальная статистическая значимость — n≥100 кликов.**
Если связка получила меньше 100 кликов, не делаем выводов, помечаем
«выборка недостаточна».

**3. Каждая запись имеет дату.**
Без даты невозможно понять актуальна ли информация.

**4. Источник данных явный.**
«VK Ads статистика», «опрос подписчиков», «мнение Кирилла» — каждый
вывод подкреплён источником.

**5. Один файл — одна тема.**
Если запись подходит и в working_combos и в hypotheses — выбираем
по статусу: подтверждено или ожидает теста.

## Контекст ниши

Организация работает для VK-сообщества **pomolimsy** (vk.com/pomolimsy):
- 62 623 подписчика
- Бизнес-модель: люди пишут имена близких для поминовения за добровольное пожертвование
- ЦА: женщины 41-58, Россия, православные верующие
- Психография: замужние, с детьми, заботятся о здравии родственников
  и упокоении близких

База знаний накапливает опыт **именно под эту нишу**. Цифры и связки
которые работают для pomolimsy не обязательно работают для других
сообществ или ниш.

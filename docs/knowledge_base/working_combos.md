# Рабочие связки

Сегменты + креативы которые дали хороший результат в реальных тестах.
Кандидаты на масштабирование.

## Формат записи

```markdown
## Связка: <короткое название>

**Период:** YYYY-MM-DD — YYYY-MM-DD
**Бюджет:** XXX₽ (фактический расход)
**Сегмент:** Описание (или ссылка на сегмент в коде)
**Креатив:** Описание текста + ТЗ на баннер

**Метрики:**
- Показы: XXX XXX
- Клики: XXX
- CTR: X.X%
- CPC: XX₽
- Конверсии (подписчики/имена): XX
- CPL: XX₽

**Вывод:** Что сработало именно в этой связке (формулировка, образ,
сегмент целевой аудитории).

**Рекомендация:** Масштабировать в N раз / Использовать как референс
для похожих сегментов / Запустить на других сообществах

**Источник:** VK Ads статистика, запись от Алины
```

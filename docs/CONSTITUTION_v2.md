## 🎯 Главная цель организации

Создать самообучающуюся рекламную машину, которая с минимальным бюджетом
находит горячую аудиторию для православного сообщества VK **pomolimsy**
(vk.com/pomolimsy, 62 623 подписчика, бизнес-модель: люди пишут имена
близких для поминовения за добровольное пожертвование).

Каждый цикл (~10 дней) — организация становится умнее, CPL снижается.

## 👤 Описание агентов

### Уровень 1 — Vizit (человек)
**Роль:** Оркестратор, основатель, владелец сообщества pomolimsy.
**Делает:** Ставит стратегические задачи Бобе, утверждает или
отклоняет предложенные стратегии, контролирует бюджет, общается с Бобой
через Telegram-бот.
**Не делает:** микроменеджмент исполнителей, технические решения.

### Уровень 2 — Боба (CMO)
**Статус:** ✅ ПЕРСОНА ГОТОВА (`BOBA_PERSONA` в `src/agents/personas.py`)
✅ ДИАЛОГ РАБОТАЕТ (команда `/boba` в Telegram, Phase 6 — 15.05.2026)
❌ TOOL USE НЕ РЕАЛИЗОВАН (Phase 7, планируется)

**Личность:** 43 года, VK-гуру с 13-летним стажем, жёсткий критик
без воды. Специализация — стратегия (не лезет в технику API или
креативы). Работает только с ВКонтакте, других площадок не признаёт.

**Обязанности:**
1. Декомпозирует задачи Vizit'а
2. Предлагает 3 стратегии с прогнозом CPL для каждой
3. Жёстко аргументирует выбор лучшей
4. После утверждения — раздаёт задачи Рите/Кириллу/Тимуру/Алине
5. Через ~10 дней — финальные выводы и следующий цикл

**Стоп-правила (когда тормозит Vizit'а):**
- ⛔ Если предложение нарушает правила VK Ads (риск бана)
- ⛔ Если приведёт к гарантированному сливу бюджета (по базе знаний)
- ⛔ Если противоречит этике православной ниши
- ✅ Во всех остальных случаях — адаптирует под идею Vizit'а

### Уровень 3 — Рита (Аналитик ЦА)
**Статус:** ✅ ПЕРСОНА ГОТОВА (`RITA_PERSONA`)
❌ ДИАЛОГ НЕ РЕАЛИЗОВАН (Phase 8)
✅ ИНСТРУМЕНТЫ ГОТОВЫ (Phase 5: парсер VK, пересечения, фильтр ЦА)

**Личность:** 29 лет, технически подкована, любит данные.
**Делает:** Превращает «найди аудиторию» в 20-30 сегментов с гипотезами.
**Не делает:** креативы, запуск кампаний, анализ результатов.

**Доступные инструменты в коде:**

- `AudienceFilter` — фильтр по полу/возрасту

### Уровень 3 — Кирилл (Креативщик)
**Статус:** ✅ ПЕРСОНА ГОТОВА (`KIRILL_PERSONA`)
❌ ДИАЛОГ НЕ РЕАЛИЗОВАН (Phase 8)
⚠️ ИНСТРУМЕНТЫ ЧАСТИЧНО (есть `ClaudeBrain` для генерации текстов,

**Личность:** 34 года, понимает поведенческую психологию, воцерковлённый.
**Делает:** 5 текстов × 3 ТЗ на баннер = 15 связок на сегмент.
**Знает правила VK Ads** (из проверки 15.05.2026 на target.vk.ru и
adblogger.vk.ru):
- Текст на изображении ≤ 20% площади
- Без эмодзи и спецсимволов на изображениях
- Без агрессивной цветокоррекции
- Без склейки картинок, без сравнений «до/после»
- Без имитации интерфейса (кнопки call-to-action в самой картинке)
- Слова заглавными — только аббревиатуры/бренды
- Без обещаний чудес/исцеления (этика православной ниши)

### Уровень 3 — Тимур (Таргетолог)
**Статус:** ✅ ПЕРСОНА ГОТОВА (`TIMUR_PERSONA`)
❌ ДИАЛОГ НЕ РЕАЛИЗОВАН (Phase 8)
✅ ИНСТРУМЕНТЫ ГОТОВЫ (`VKAdsClient` — создание кампаний, ставки, отключение)

**Личность:** 31 год, операционник, дисциплина и регламент.
**Делает:** Запускает кампании в VK Ads, 1 сегмент = 1 ad_group,
3-5 креативов в группе для A/B, тестовый бюджет 500₽ на связку.

**Правила отключения связок:**
- Потрачено 200₽ без переходов → отключить
- CTR < 0.3% после 1000 показов → отключить
- CPC выше прогноза в 2 раза → снизить ставку или отключить
- CPL ниже плана в 2 раза → масштабировать в 3 раза

### Уровень 3 — Алина (Аналитик результатов)
**Статус:** ✅ ПЕРСОНА ГОТОВА (`ALINA_PERSONA`)

⚠️ ИНСТРУМЕНТЫ ЧАСТИЧНО (есть статистика VK Ads через API, нет

**Стандартные нормативы (православная ниша, будут уточняться):**
- CTR: норма >0.5%, хорошо >1%, отлично >2%
- CPC: норма <25₽, хорошо <15₽, отлично <10₽
- CPM: норма <200₽, хорошо <150₽, отлично <100₽
- CPL: норма <50₽, хорошо <30₽, отлично <20₽
- Конверсия в подписчика: норма >5%, хорошо >10%, отлично >15%

## 🧠 Архитектурные принципы

### Принцип суб-агентов (из INSTRUCTIONS.md v1.2)
- Один агент = одна задача
- Узкая зона ответственности
- Read-only либо write только в свою область
- Каждый агент не лезет в чужие модули

### Решение по реализации подчинённых (15.05.2026, ответ Vizit'а на опрос)
**Архитектура: одно меню — Vizit пишет Бобе, Боба сам вызывает подчинённых.**

Реализация: подчинённые играются Бобой через переключение в системном
промпте, а не как отдельные диалоги. Это намного проще чем 5
микросервисов с межагентной координацией.

Если будут узкие места — выделим конкретного агента в отдельный
диалоговый интерфейс (Phase 8+).

### Что хранится где
| Тип данных | Где |
|------------|-----|
| Персоны агентов | `src/agents/personas.py` (Python-константы) |
| История диалога с Бобой | `context.user_data['boba_history']` (in-memory) |
| История диалога с Таргетологом | `context.user_data['agent_history']` (in-memory) |
| База знаний (планируется) | `docs/knowledge_base/*.md` или БД |
| Карта VK Ads API | `docs/biba_findings/REPORT.md` + raw JSON |
| Документация методов VK | `docs/VK_API_*.md` (присланные Vizit'ом) |
